# v1.4 evaluation baseline

`baseline.json` is generated by `backend/scripts/capture_baseline.py`. It records actual backend, frontend unit, and browser suite results plus the compatibility fixture categories. It does not contact an LLM provider.

Regenerate the complete baseline:

```bash
cd backend
/Users/zhifengzhang/python_env/env_ai_build/bin/python scripts/capture_baseline.py
```

For a faster backend/frontend-only check:

```bash
/Users/zhifengzhang/python_env/env_ai_build/bin/python scripts/capture_baseline.py --skip-browser
```

The browser suite uses isolated ports `18010` and `18011`. Provider-specific evaluations remain a separate, opt-in activity and are marked `skipped` in the baseline.
