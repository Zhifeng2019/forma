# v1.4 evaluation baseline

The checked-in `baseline.json` and `generation.json` are historical AppSpec compiler evidence. The compiler and its generation-quality runner have been removed. New suite-only baselines are generated by `backend/scripts/capture_baseline.py`. It records actual backend, frontend unit, and browser suite results plus the compatibility fixture categories. It does not contact an LLM provider.

Capture current regression suites:

```bash
cd backend
/Users/zhifengzhang/python_env/env_ai_build/bin/python scripts/capture_baseline.py
```

For a faster backend/frontend-only check:

```bash
/Users/zhifengzhang/python_env/env_ai_build/bin/python scripts/capture_baseline.py --skip-browser
```

Captures write `current-baseline.json` by default, preserving the archived compiler evidence. The browser suite uses isolated ports `18010` and `18011`. Provider-specific evaluations remain a separate, opt-in activity and are marked `skipped` in the baseline.
